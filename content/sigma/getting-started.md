# Getting started

## 1. Buy a subscription

1. Open the [VargaLABS store](https://store.vargalabs.com/).
2. Select Pro or Team.
3. Select monthly or yearly billing.
4. For Team, select the number of seats. The minimum is 3.
5. Complete payment on the Stripe checkout page.

See [Billing](/sigma/billing/) for prices and application options.

## 2. Get your install key

The store sends your install key by email after it creates your licence. The checkout result page can also return the key when it is ready.

If the result is still pending, wait for the delivery email. A pending result does not mean that you must buy again.

An install key has five groups of five characters. This example shows the format only. It is not a key for use:

```text
7K3QD-M9XWT-4HRZP-C2N8F-VJ6YB
```

Keep the email. You use the install key to identify your licence.

## 3. Enter the key

1. Open Settings in the product.
2. Select Install Key.
3. Enter the key from your email.

You can use lower-case letters. Spaces and missing dashes are accepted.

A licence check-in uses the install key and a hashed machine fingerprint to request a signed licence token. See [Licensing](/sigma/licensing/) for token life and offline use.

## 4. Link an account if needed

Account linking is separate from payment. A link connects this installation to an account at a sign-in provider.

Linking is optional when the product only suggests it. If the licence requires linking, complete it before the displayed deadline. See [Account linking](/sigma/account-linking/) for the steps.

For a team, also read [Team setup](/sigma/team-setup/).
